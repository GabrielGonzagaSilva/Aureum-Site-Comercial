# Aureum — Site Comercial

Site institucional/comercial público da Aureum, separado do Hub interno.

## Estrutura

- `index.html` — home comercial.
- `paises/` — subpáginas de destinos.
- `assets/css/styles.css` — sistema visual e responsividade compartilhados.
- `assets/js/config.js` — configuração de canais/links externos.
- `assets/js/site.js` — comportamento compartilhado.
- `docs/` — arquitetura, processo de manutenção e changelog.

## Publicação

A estrutura é compatível com hospedagem estática, incluindo GitHub Pages. O repositório poderá ser conectado depois sem alterar a arquitetura.

## Regra de manutenção

Toda alteração funcional, visual, estrutural ou de conteúdo relevante deve gerar uma entrada em `docs/CHANGELOG.md`.
